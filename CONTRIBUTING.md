# Contributing

Ding is open source so you can read it, build it, and fork it. It is **not accepting outside code contributions**: pull requests
will be closed without review.

That's deliberate. Ding is licensed under the GPLv3 and is also distributed on the Mac App Store, whose terms the GPL doesn't
allow for code the distributor doesn't own. Keeping all the code written by one author keeps that possible.

## What is welcome

- **Bug reports and feature ideas:** [open an issue](https://github.com/needyaz/ding/issues). Include your macOS version, what
  calendar account types you use (iCloud, Google, Exchange), and, for link problems, the *shape* of the invite (redact real meeting
  IDs and passcodes).
- **Forks:** the GPLv3 lets you fork and change Ding freely, as long as your fork stays under the GPLv3.

## If you're building it yourself

See the [README](README.md) for build steps and the project layout. `make test` runs everything.
