# Delta: Settle the spec conflicts found when Ding joined the factory

- Unit: ding
- Delta id: ding-20261109-1
- Status: proposed

## What changes

Ding's baseline recovery (2026-11-09) left seven requirements marked X, where sources disagree, plus one unspecced behavior that confuses users. The owner settled the product questions on 2026-11-09:
- the defaults stay as shipped: a 5-minute notification, and the screen reminder style None;
- the style keeps its shipped label "Full-screen alert";
- the "events without a meeting link" switch stays one setting, which is relabelled and moved so it plainly covers both notifications and screen reminders.

The rest are facts or bugs:
- the MCP tool description names the wrong reply field;
- a test builds the real `AppModel`, which touches the real notification center;
- the release and decision documents are stale;
- the listing README claims a check that does not exist;
- README.md still says Ding is coming to the Mac App Store, but it has been live since 2026-11-09 (app id 6829270522).

This change makes every one of those rows true and testable, so no X row remains.
